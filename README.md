Канбан-доска — это визуальный инструмент для управления рабочим процессом, который помогает отслеживать задачи на разных этапах их выполнения. Представляет собой поле, разделенное на колонки (например, «В работе», «Готово»), по которым перемещаются карточки, обозначающие задачи. Это помогает командам упорядочить работу, повысить эффективность и избежать хаоса.

Как работает:
- Карточки: Каждая задача представлена в виде карточки, на которой указаны детали: что нужно сделать и какой у нее дедлайн.

-Колонки: Колонки на доске соответствуют этапам рабочего процесса, например: «Без статуса», «Нужно сделать», «В работе», «Тестирование», «Готово».

-Перемещение карточек: Когда команда начинает работу над задачей, карточка перемещается из колонки «Нужно сделать» в «В работе». По мере завершения этапов, карточка двигается дальше по доске, пока не попадет в последнюю колонку «Готово».

Ключевые элементы и преимущества:
- Визуализация: Позволяет видеть весь поток работы и статус каждой задачи на одном экране.

- Ограничение незавершенной работы: Помогает ограничить количество задач, которые можно выполнять одновременно, что предотвращает перегрузку и повышает качество.

- Улучшение командной работы: Дает всем членам команды ясное представление о текущем положении дел.

- Адаптивность: Доски можно настраивать под конкретные нужды команды, добавляя или убирая колонки в соответствии с её рабочим процессом.

Функции приложения:
- функция создания и получения задачи;
- функция получения одной задачи по id, с возможностью редактирования и её удаления.

В данном приложение присутствует следующая функциональность: 
- видны ошибки, которые присылает сервер при редактировании, удалении или добавлении задачи;
- обработан ввод данных в инпуты так, чтобы нельзя было отправить пустые поля или поля с пробелами;
- обработаны ошибки при падении сервера во всех запросах;
- добавлена более сложная анимация загрузки;
- реализована обработка ситуации, где задач пока что нет;
- стилизована страница 404 в том же формате, что и остальные страницы, со ссылкой на главную страницу; 
- карточки с задачами можно перетаскивать из одного статуса в другой;
- возможность смены темы со светлой на темную и наоборот;
- добавлены красивые уведомления для успешных действий, ошибок и предупреждений.
